# falqor

Demo landing page / storefront for **FALQOR**, a luxury Eau de Parfum brand. *Beyond Ordinary.*

**Live demo:** https://devriazul.github.io/falqor/

## Features
- 10 fragrances (5 men's, 5 women's), each in 3 luxury levels: Affordable ($59), Premium ($129), Ultra ($249)
- Filter by collection, sort, per-card tier switcher, hover to see the tier line-up
- Quick-view modal with gallery, notes pyramid, tier picker and quantity
- Cart drawer with free-shipping progress, wishlist, and discovery set (saved in localStorage)
- 3-step scent finder quiz
- Responsive, plain static HTML/CSS/JS with no build step

Demo only: prices are placeholders and checkout takes no payment.

## Run locally
```
python3 -m http.server
```
